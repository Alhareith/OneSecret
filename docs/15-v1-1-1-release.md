# الإصدار V1.1.1: توثيق وإطلاق موثقان

## النطاق

V1.1.1 إصدار تصحيحي لا يغير سلوك إنشاء الرسائل أو تشفيرها أو كشفها أو الصلاحية أو Secret Code. يجمع التحسينات التي تلت إطلاق V1.1.0 في إصدار موثق واحد: تثبيت بوابة الجودة، تنقيح README للعرض العام، وتحديث أرقام النسخة في الواجهة والخادم.

## ما دخل الإصدار

| المجال | التغيير |
|---|---|
| بوابة الجودة | صحح ترتيب إعداد pnpm وNode.js في GitHub Actions، ثم تحققت بوابة الجودة بنجاح من TypeScript وبناء Vite واختبارات Python |
| README | أصبح README وثيقة منتج وتقنية مستقلة؛ أزيلت منه الصياغات الأكاديمية والخطاب الموجه، مع بقاء الشرح الأمني واللقطات والمخططات |
| التوثيق | أضيف سجل النشر العام والإصدارات، وربطت الفهارس به وسجل الإصدارات |
| أرقام النسخة | أصبحت حزمة الواجهة وواجهة FastAPI تحمل الرقم `1.1.1` بما يتفق مع الإصدار المنشور |

## ما لم يتغير

لا توجد ترحيلات قاعدة بيانات أو واجهات API جديدة أو تغييرات في AES-256-GCM أو حدود طلبات V1.1 أو منطق الرسائل. يبقى V1.1.0 أساس التحصين التشغيلي، بينما V1.1.1 إصدار صيانة وتوثيق وتحسين جودة الإطلاق.

## التحقق قبل الإصدار

| الفحص | المطلوب |
|---|---|
| اختبارات Python | نجاح `pytest -q` واختبارات V1.1 البالغ عددها 71 |
| واجهة TypeScript | نجاح `pnpm check` داخل `frontend/` |
| بناء الإنتاج | نجاح `pnpm build` داخل `frontend/` |
| الفروقات | نجاح `git diff --check` وعدم وجود مفتاح أو بيانات اختبار ضمن الملفات المتتبعة |
| GitHub Actions | تشغيل ناجح بعد رفع الإصدار على فرع `main` |

## الإصدار والنشر

بعد تحقق جميع البنود، ينشأ tag باسم `v1.1.1` وإصدار GitHub بعنوان **OneSecret V1.1.1 — توثيق وجودة الإطلاق**. يظل `v1.0.0` و`v1.1.0` محفوظين كمعالم منفصلة لتاريخ المنتج.
