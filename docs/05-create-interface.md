# المرحلة 5: واجهة إنشاء السر الثنائية اللغة

## هدف المرحلة

إنشاء الصفحة التي يراها المرسل. يكتب رسالته، يختار مدة الصلاحية، ثم ينشئ رابطًا للمشاركة. هذه المرحلة لا تعرض السر للمستلم؛ صفحة Reveal تأتي لاحقًا.

## تجربة المستخدم

```text
يختار اللغة
     ↓
يكتب رسالة سرية
     ↓
يختار مدة الصلاحية
     ↓
يضغط Create secret
     ↓
React يرسل الطلب إلى FastAPI
     ↓
يعرض الموقع رابط المشاركة فقط
```

## الحقول

| الحقل | ما يكتبه المستخدم؟ | لماذا نحتاجه؟ |
|---|---|---|
| الرسالة السرية | نص غير فارغ | هذا النص سيرسله React إلى Python ليُشفّر |
| مدة الصلاحية | 5 أو 15 أو 60 دقيقة أو 24 ساعة | يحولها React إلى وقت انتهاء UTC قبل الإرسال |
| اللغة | العربية أو الإنجليزية | يبدل النصوص والاتجاه، لا يغير الرسالة نفسها |

## الحالات التي تظهر في الصفحة

| الحالة | ماذا يحدث؟ |
|---|---|
| قبل الإنشاء | يظهر النموذج فقط |
| رسالة فارغة | يظهر تنبيه محلي ولا يرسل طلبًا للخادم |
| أثناء الإنشاء | يتعطل الزر وتظهر حالة انتظار |
| نجاح الإنشاء | يظهر رابط `/s/{id}` وزر نسخ |
| فشل الخادم | تظهر رسالة عامة؛ لا نعرض تفاصيل الخادم الحساسة |

## اللغتان والاتجاه

كل نص واجهة يوجد في `frontend/src/lib/i18n.ts`. عند اختيار العربية يصبح `dir="rtl"`، وعند اختيار الإنجليزية يصبح `dir="ltr"`. لا نضع نصوص الواجهة داخل ملف React حتى يمكن مراجعتها أو إضافة لغة أخرى لاحقًا.

## الاتصال بالخادم

`frontend/src/lib/api.ts` مسؤول عن طلب واحد في هذه المرحلة: `POST /api/secrets`. يستقبل من الواجهة `secret_id` و`plaintext` و`expires_at`، ثم يعيد المعرّف ووقت الانتهاء والحالة. هذا الرد لا يحتوي على النص أو ciphertext أو المفتاح.

## ما لا يدخل في هذه المرحلة

لا يوجد Reveal، ولا صفحة مستقبل، ولا حسابات، ولا PIN، ولا رفع ملفات. كما لا نعتمد على حماية الواجهة وحدها؛ الخادم يبقى المسؤول عن التشفير والتحقق.

## الاختبارات

نفحص بناء TypeScript، والتحول بين RTL وLTR، والتحقق من الرسالة الفارغة، وتعطيل زر الإرسال أثناء الطلب، وظهور رابط المشاركة عند النجاح ورسالة عامة عند الفشل.

## سجل التنفيذ

تم إنشاء `i18n.ts` للنصوص العربية والإنجليزية، و`api.ts` لطلب الإنشاء فقط، و`CreateSecretPage.tsx` للنموذج. لا توجد نصوص واجهة مخفية داخل منطق API، ولا تتعامل React مع المفتاح أو ciphertext.

| الاختبار | النتيجة |
|---|---|
| بناء TypeScript وVite | ناجح |
| العربية واتجاه RTL | ناجح في المعاينة |
| الإنجليزية واتجاه LTR | ناجح في المعاينة |
| رسالة فارغة | يظهر تنبيه محلي ولا يرسل الطلب |
| إنشاء رسالة اختبار عبر FastAPI | ظهر رابط مشاركة صحيح بصيغة `/s/{id}` |
| نسخ الرابط | ظهر تأكيد «تم نسخ الرابط» |
| إيقاف FastAPI ثم الإرسال | ظهرت رسالة عامة «تعذر إنشاء الرابط الآن. حاول مرة أخرى.» من دون كشف تفاصيل تقنية |
| شاشة هاتف 390×844 | بقي العنوان والنص والحقل وأداة اللغة واضحين داخل العرض الصغير، مع تمرير عمودي طبيعي للوصول إلى بقية النموذج |

استخدمت المعاينة المحلية مفتاحًا مؤقتًا مولدًا للاختبار وقاعدة SQLite مؤقتة. المفتاح الحقيقي للإنتاج يبقى في إعدادات المشروع الآمنة ولا يظهر في React أو قاعدة البيانات أو هذه الوثيقة.

## ما بقي للمرحلة التالية

الرابط المنشأ يعرض الآن صفحة غير موجودة لأن صفحة المستلم لم تُبن بعد. المرحلة التالية هي صفحة **Reveal** التي تقرأ حالة السر أولًا ثم تطلب الكشف الصريح مرة واحدة.
