# V1.2.1 — رمز إلغاء مختصر ومدخل دائم

## النطاق

هذا إصدار تصحيحي فوق V1.2.0. لا يغير تشفير الرسالة ولا مدة الصلاحية ولا إلغاء الرابط الذري. يحسن فقط طريقة وصول المرسل إلى الإلغاء وطول الرمز الذي يكتبه.

## القرار

يتكون الرمز من خمسة رموز عشوائية من الأبجدية `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`. استبعدت الرموز المتشابهة بصريًا مثل `I` و`L` و`O` و`0` و`1`، فيصبح إدخاله وقراءته أسهل. مساحة الاحتمالات هي `32^5 = 33,554,432`.

لم يُعتمد رمز من أربعة رموز، لأنه يقلل مساحة الاحتمالات بصورة ملموسة. ومع أن الرمز القصير ليس بديلًا عن مفتاح تشفيري طويل، تحده الخدمة بثلاث محاولات خاطئة لكل مصدر وخمس لكل رابط خلال 15 دقيقة داخل نسخة FastAPI الواحدة. توصي OWASP بحماية مسارات التحقق من التخمين وحدّ المحاولات، ولا ينبغي اعتبار الحد داخل الذاكرة حماية موحدة عند تشغيل عدة نسخ من الخادم [1].

## تجربة المرسل

يبقى رمز الإلغاء ظاهرًا في بطاقة النجاح مرة واحدة فقط، بخط واضح وزر نسخ. يظهر نموذج إلغاء رابط موجود أسفل واجهة الإرسال مباشرة، فلا يحتاج المرسل إلى إنشاء رسالة جديدة ليصل إلى الإلغاء. يبقى الرمز داخل حقل كلمة مرور ولا يحفظ في localStorage أو الرابط أو السجل.

## التحقق

نجحت اختبارات الإصدار بعد توثيق التغيير، وتشمل طبقة الخادم والواجهة والتدفق التفاعلي ببيانات اختبار فقط.

| المسار | النتيجة |
|---|---|
| Python / FastAPI | `83 passed` في pytest |
| TypeScript وVite | فحص الأنواع وبناء الإنتاج ناجحان |
| HTTP والمتصفح | تدفق إلغاء صحيح وخاطئ، قبول أحرف صغيرة، مدخل دائم، وعربية/إنجليزية ببيانات اختبار فقط |
