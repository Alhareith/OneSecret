# المرحلة 10: تحسين الإرسال والمشاركة

## الهدف والنطاق

تضيف هذه المرحلة تحسينات واجهة وتجربة استخدام فقط. بقي التشفير، وFastAPI، وقاعدة البيانات، وسلوك الصلاحية القائم آنذاك كما هي. تغير نموذج الوصول لاحقًا في المرحلة 11 إلى العرض المتكرر حتى الانتهاء مع إتلاف اختياري وSecret Code. لا تضيف هذه المرحلة حسابات أو Popup أو مكتبات واجهات جديدة.

| التحسين | القرار المنفذ |
|---|---|
| مدة أقصر | أضيف خيار **دقيقة واحدة** مع بقية الخيارات، وهو يقع ضمن حد 24 ساعة الذي يتحقق منه الخادم حاليًا |
| الخط واللون | استُخدم Cairo بأوزان حتى 900 للعربية، وخلفية صافية هادئة `#f5f7fb` بدل اللون الكريمي السابق |
| الرابط | يظهر جزء مختصر فقط بالشكل `…/s/xxxxxxxx…xxxxxx`، بينما يبقى الرابط الكامل داخل الذاكرة للنسخ أو المشاركة |
| المشاركة | زر مشاركة يستدعي `navigator.share` ونافذة الهاتف الأصلية فقط؛ عند غيابها تظهر ملاحظة قصيرة لا روابط تطبيقات مخصصة |
| صفحة المستلم | CTA واحد هادئ يظهر بعد عرض النص فقط، وينقل مباشرة إلى `/` لإنشاء رسالة جديدة |

## تجربة المستخدم الحالية

بعد إنشاء السر، لا يرى المرسل نطاقًا طويلًا أو معرّفًا كاملًا يزاحم الشاشة. يرى رابطًا مختصرًا وزرين متجاورين: «نسخ الرابط» و«مشاركة». النسخ والمشاركة يعملان دائمًا على الرابط الكامل، ولذلك لا تتغير صلاحية الرابط أو قدرته على الفتح.

بعد كشف الرسالة بنجاح، تظهر أسفلها عبارة قصيرة «أُرسلت بأمان عبر OneSecret» ثم CTA واحد: «هل تريد إرسال رسالة خاصة؟ أرسل رسالتك الآمنة →». لا يظهر في حالات الرابط المستهلك أو المنتهي أو غير المتاح، ولا يضيف أي طلب خادمي أو تغيير على طلب Reveal.

## التحقق المنفذ

| الفحص | النتيجة |
|---|---|
| اختيار «دقيقة واحدة» وإنشاء رسالة | ناجح؛ أنشأ FastAPI رابطًا صالحًا من دون تعديل الخادم |
| الرابط المختصر | ظهر على الواجهة من دون عرض الرابط الكامل |
| زر النسخ | نسخ الرابط الكامل وأظهر تأكيدًا واضحًا |
| زر المشاركة في سطح المكتب التجريبي | لم تكن `navigator.share` متاحة؛ ظهرت ملاحظة قصيرة تطلب نسخ الرابط من الزر المستقل، بلا روابط تطبيقات داخل الموقع |
| صفحة المستلم | عرضت الرسالة تلقائيًا ثم CTA واحدًا فقط |
| CTA | انتقل إلى صفحة إنشاء رسالة جديدة بنجاح |
| العربية والإنجليزية | العربية RTL والإنجليزية LTR، وظهر `1 minute` في الإنجليزية |
| وحدة تحكم المتصفح | لا أخطاء أو تحذيرات في مسارات الاختبار |
| `pnpm test` | 3 اختبارات ناجحة |
| `pnpm check` و`pnpm build` | ناجحان؛ يبقى Reveal في ملف مؤجل منفصل |
| `pytest -q` | 60 اختبار Python ناجحًا؛ تحذير خارجي واحد من FastAPI/TestClient فقط |

## ملاحظة المشاركة الأصلية

لا تفتح ميزة المشاركة تطبيقًا ولا ترسل رسالة تلقائيًا. إن كان الهاتف يدعم ورقة المشاركة الأصلية، يختار المستخدم تطبيقًا مثبتًا أو جهة مشاركة بنفسه. عند اختياره، يتولى نظام الهاتف فتح التطبيق؛ لا ينشئ الموقع روابط واتساب أو تلغرام أو بريد مخصصة.

## اعتماد نافذة مشاركة الهاتف الأصلية

حُذفت لوحة مشاركة الموقع وروابط واتساب وتلغرام والبريد المخصصة. يستدعي الزر `navigator.share` مباشرة مع الرابط الكامل من حدث النقر، فيعرض الهاتف التطبيقات المثبتة فعليًا ويفتح التطبيق الذي يختاره المستخدم. في المتصفح غير الداعم لا تظهر بدائل داخل الموقع؛ تظهر فقط ملاحظة قصيرة بأن مشاركة الجهاز غير متاحة مع بقاء زر النسخ المستقل.

أُنشئت رسالة اختبار وفُتح زر المشاركة في متصفح سطح مكتب غير داعم؛ لم تظهر أيقونات أو روابط لتطبيقات، بل الملاحظة المختصرة المتوقعة فقط. واختُبر استدعاء واجهة مشاركة الجهاز محليًا من دون إرسال رابط إلى تطبيق خارجي؛ استقبلت الواجهة الأصلية المحاكية كائنًا يحوي `title` و`text` والرابط الكامل فقط.
