# سياسة الأمان

## نطاق المشروع

OneSecret مشروع مشاركة رسائل نصية مؤقتة. يركز الفحص الأمني على AES-256-GCM، صلاحية الرابط، الإتلاف الاختياري، Secret Code، حدود الطلبات، وسلوك التخزين المؤقت في المتصفح.

## الإبلاغ المسؤول

لا تنشر أي مفتاح أو رسالة أو Secret Code أو رابط صالح في issue أو pull request. عند اكتشاف مشكلة، استخدم بيانات اختبار فقط، واشرح الأثر وخطوات إعادة الإنتاج على مستوى عام. إن كانت ميزة الإبلاغ الأمني الخاص مفعلة في المستودع، استخدمها؛ وإلا افتح issue مختصرًا بلا معلومات حساسة.

## ما لا يعد سرًا آمنًا للنشر

المعرف الموجود داخل رابط `/s/{id}` يجب التعامل معه بحذر. لا تنشر روابط عاملة أو لقطات تحتوي على رسائل حقيقية، ولا ترفع ملفات إعداد بيئة أو قواعد بيانات محلية أو سجلات تشغيل.

## حدود الإصدار الحالي

لا يدعي المشروع تشفيرًا طرفًا إلى طرف، ولا يستطيع منع نسخ المحتوى أو تصويره بعد الكشف. محدد الطلبات في V1.1 داخل ذاكرة عملية خادم واحدة، لذلك يحتاج التشغيل متعدد النسخ إلى مخزن مركزي مستقل.
