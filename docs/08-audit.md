# المرحلة 8: التدقيق الشامل والإصلاح

## الهدف

فحص OneSecret كمنتج كامل، لا كأجزاء منفصلة فقط. شمل التدقيق تشفير Python، وحفظ البيانات، ومسارات API، وواجهة React، والتشغيل الموحّد، وإعداد المفتاح، وقاعدة بيانات المشروع. كان المبدأ: **أي خلل يثبت باختبار، ثم يصلح، ثم تعاد الاختبارات من البداية**.

> نجاح الاختبارات لا يعني أن النظام يحمي من كل شيء في العالم؛ بل يعني أن الحالات الموثقة أدناه تصرفت كما صُممت بعد اختبارها.

## ما الذي فُحص؟

| المجال | ما اختبرناه | النتيجة |
|---|---|---|
| تشفير AES-GCM | نص عربي وإنجليزي، مفتاح وnonce خاطئان، ciphertext وnonce تالفان | ناجح؛ البيانات التالفة تعيد نتيجة عامة ولا تكشف سبب التشفير الداخلي [1] |
| خدمة الأسرار | الإنشاء، الحالة، الاستهلاك الذري، الانتهاء، وتزامن طلبات Reveal | ناجح؛ يسمح طلب واحد فقط بالكشف |
| API | التحقق، المعرّف غير الصحيح، التعارض، الرابط المفقود، وAPI غير المعروف | ناجح؛ لا يعكس plaintext أو حقل `input` في أخطاء التحقق |
| واجهة React | العربية RTL، الإنجليزية LTR، رسالة فارغة، النسخ، Reveal، used، missing | ناجح في المتصفح؛ لا توجد أخطاء JavaScript مسجلة أثناء التدفق |
| الهاتف | Create وReveal على 390×844 | ناجح؛ لا تجاوز أفقي، مع تمرير رأسي طبيعي |
| التشغيل الموحّد | ملفات React، `/s/{id}`، API 404، health endpoint | ناجح على FastAPI نفسه؛ fallback يعيد React لمسارات الواجهة فقط [2] |
| الاعتماديات | Python وواجهة React | `pip-audit`: لا ثغرات Python معروفة؛ تدقيق frontend: بلا ثغرات مُبلّغ عنها |

## العيوب التي اكتشفها التدقيق وأصلحها

| العيب المثبت | الخطر أو الأثر | الإصلاح | اختبار الحماية |
|---|---|---|---|
| تلف Base64 كان يترك الرابط في حالة `active` | قد تتكرر محاولة كشف الرابط التالف | تثبيت `used_at` قبل فك Base64 أو AES-GCM | اختبارات ciphertext وnonce وBase64 التالفين |
| `mysql://` لم يحدد PyMySQL | فشل محرك SQLAlchemy عند التشغيل | تحويله إلى `mysql+pymysql://` | اختبار عنوان MySQL وSQLite |
| SSL في عنوان MySQL كان نص JSON | PyMySQL ينتظر قاموسًا لا نصًا | فصل `ssl` وتحويله إلى `connect_args` | اختبار JSON صحيح وخطأ SSL غير صالح |
| fallback الواجهة يلتقط `/api/*` غير المعروف | رد HTML بـ200 بدل 404 API | إعادة 404 JSON لمسارات API غير المعروفة | اختبار `/api/not-a-route` |
| FastAPI يعكس plaintext في خطأ 422 | تسرب محتمل للنص المرفوض | معالج تحقق عام يعيد `Invalid request` فقط | اختبار رسالة طويلة بعلامة حساسة |
| رسالة واجهة قديمة بعد تغيير اللغة | اختلاط العربية والإنجليزية | مسح رسائل الحالة المؤقتة عند تغيير اللغة | اختبار متصفح: خطأ عربي ثم English |
| نصوص تقول إن Reveal «مرحلة لاحقة» | معلومات مضللة للمستخدم | تحديث النصوص العربية والإنجليزية | فحص الواجهة بعد البناء |
| اعتماديات Python غير مثبتة | بناء Docker غير متكرر | تثبيت الإصدارات وإضافة `httpx2` للاختبارات | بيئة venv نظيفة و60 اختبارًا ناجحًا |

## اختبار بيئة المشروع الحقيقية

اختبرنا المفتاح من خلال خدمة FastAPI بدأت من بيئة المشروع ثم استدعي health endpoint الذي يعيد فقط `{ "status": "ok" }`. لا يطبع الاختبار المفتاح ولا يرسله إلى المتصفح. خُزّن المفتاح الجديد في إعدادات المشروع السرية وليس في الكود أو Git أو قاعدة البيانات.

تحققنا أيضًا من قاعدة بيانات المشروع الفعلية. أُنشئ جدول `secrets` بأعمدة `id` و`ciphertext` و`nonce` وأوقات الإنشاء والانتهاء والاستخدام فقط، مع فهرس `expires_at`. لا يوجد عمود `plaintext` أو مفتاح تشفير. أُنشئ سر تدقيق غير حساس عبر API الحقيقي، وتأكدنا من أطوال ciphertext وnonce فقط، ثم كشفناه مرة واحدة وحذفنا صف التدقيق؛ لم يبق أي سجل اختبار في القاعدة.

## ما لم ندّعه

لا يدّعي OneSecret تشفيرًا طرفيًا لطرف؛ خادم Python يرى النص وقت الإنشاء ووقت Reveal، لكنه لا يخزنه واضحًا. لا يستطيع الموقع منع تصوير الشاشة أو ما يفعله المستلم بعد القراءة. لم نبنِ حسابات أو PIN أو إلغاء رابط أو حدًا للطلبات، ولم ننشر الصورة علنًا بعد. كما لم نختبر بناء Docker محليًا لأن هذه البيئة لا توفر Docker؛ اختبرنا أوامر البناء والخدمة نفسها، ويظل بناء الصورة خطوة تحقق عند النشر.

يبقى تدقيق `pnpm audit` في **قالب Node الجذري** يحتوي تنبيهات تخص أدوات القالب غير المستخدمة في صورة OneSecret الموحّدة؛ Dockerfile لا يثبت تلك الحزم ولا يشغّل خادم tRPC القديم. أما `frontend/` الذي يبنيه Docker فنجح تدقيقه بلا ثغرات مُبلّغ عنها.

## القرار بعد التدقيق

الدورة الأساسية للمشروع صالحة للاختبار والنشر: إنشاء نص، تشفيره داخل Python، تخزين مشفر، رابط عام، كشف صريح مرة واحدة، انتهاء صلاحية، واجهتان عربيتان/إنجليزيتان، وبيئة قاعدة بيانات ومفتاح تم التحقق منهما. قبل النشر العلني، يوصى بإضافة **حد للطلبات** لتقليل التخمين والإساءة، ثم النشر من واجهة المشروع وفحص السجلات والرابط الدائم.
