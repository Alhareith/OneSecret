# مصادر تحليل خارطة تطوير V1

هذا الملف يجمع النتائج المصدرية التي ستبنى عليها خارطة تطوير OneSecret، ولا يغيّر أي سلوك في التطبيق.

| المصدر | نتيجة ذات صلة بخارطة التطوير | الأثر العملي على OneSecret |
|---|---|---|
| [OWASP Password Storage Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html) | لا تُخزن كلمات المرور كنص صريح؛ يلزم salt فريد وخوارزمية اشتقاق بطيئة ومكلفة نسبيًا. توصي بـArgon2id، وتذكر scrypt بديلًا عندما لا يتاح Argon2id. | يبرر الاستمرار في اشتقاق Secret Code مع salt، وإضافة اختبار إعدادات الاشتقاق قبل أي تغيير لها. |
| [OWASP REST Security Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/REST_Security_Cheat_Sheet.html) | المعلومات الحساسة لا تذهب في URL؛ يوصى بالتحقق من المدخلات، أخطاء عامة، وحدود مناسبة للطلبات، كما يوصي `Cache-Control: no-store` للاستجابات الحساسة. | الأولوية التالية هي حدود محاولات الكشف والكود، ورؤوس عدم التخزين، وسجل أمني مختصر لا يحوي محتوى الرسائل أو Secret Code. |
| [NIST SP 800-63B](https://pages.nist.gov/800-63-4/sp800-63b.html) | توثق الإرشادات أن محاولات التحقق من الأسرار يجب حمايتها من التخمين، وأن القنوات المحمية ضرورية عند التحقق من أسرار المصادقة. | يبقى HTTPS شرطًا للتشغيل، ويُضاف حد للمحاولات الفاشلة للكود لكل رابط/مصدر قبل التفكير بالحسابات أو ميزات أكبر. |
| [Onetime Secret Security Best Practices](https://docs.onetimesecret.com/en/security-best-practices/) | توصي بأقصر مدة عملية، وpassphrase للأسرار الأشد حساسية، ومشاركة الرابط وpassphrase عبر قنوات مختلفة، ومراجعات أمنية دورية. | يؤكد أن الرسالة التوضيحية القصيرة للمرسل حول فصل الرابط عن Secret Code أهم من إضافة ميزات جديدة الآن. |
| [Bitwarden Send Lifespan](https://bitwarden.com/help/send-lifespan/) | تفرّق بين انتهاء الوصول، والحذف النهائي، وحد العرض، والتعطيل اليدوي. | يبرر أن تكون «إلغاء الرابط» و«حدّ المشاهدات» ميزتين منفصلتين في مرحلة لاحقة، لا تعديلًا خفيًا لموعد الانتهاء الحالي. |
| [OWASP File Upload Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html) | تؤكد أن رفع الملفات يحتاج allowlist للأنواع، وفحصًا مستقلاً للمحتوى والتوقيع، وحدود حجم، واسم تخزين مولد، ومكان تخزين معزول، وتوضح أن إعادة ترميز الصور تقلل المحتوى الضار المضمن. | يجعل مرحلة الصور لاحقة ومحدودة: صورة واحدة، أنواع صور محددة، حد حجم، إعادة ترميز وإزالة metadata، وتخزين ملفات منفصل؛ لا PDF أو فيديو أو أنواع عامة في أول إصدار للصور. |

> هذه المصادر إرشادية لتصميم منتج صغير، وليست شهادة امتثال أو ادعاء أن OneSecret يحقق مستويات NIST للمصادقة.
