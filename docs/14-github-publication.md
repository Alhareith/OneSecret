# النشر العام على GitHub

**تاريخ النشر:** 27 أغسطس 2026

**المستودع:** [Alhareith/OneSecret](https://github.com/Alhareith/OneSecret)
**الحالة:** عام، مع فرع رئيسي `main` وأربعة إصدارات منشورة وبوابة جودة ناجحة.

## هدف النشر

نشر المشروع هنا ليس مجرد رفع ملفات. الهدف أن يستطيع الزائر التقني فهم الفكرة وقراءة حدودها الأمنية ورؤية طريقة تنظيمها واختبارها من أول زيارة. لذلك يحمل المستودع شيفرة OneSecret الفعلية فقط: `frontend` و`backend` و`docs`، ولا يحمل قالب المنصة غير المستخدم أو ملفاته العامة.

## ما ظهر في صفحة المستودع

| العنصر | النتيجة |
|---|---|
| العنوان والوصف | اسم `OneSecret` ووصف مختصر يذكر الرسائل المؤقتة وAES-256-GCM وFastAPI وReact |
| README | ملف عربي منظم يشرح القيمة ونموذج الحماية والمعمارية والاختبارات وخارطة الطريق |
| التقنيات | شارات React وFastAPI وPython وTypeScript وSQLAlchemy وAES-256-GCM |
| صور التطبيق | لقطتان حقيقيتان ببيانات اختبار فقط: الإنشاء وعرض الرسالة |
| الجودة | بوابة GitHub Actions لفحص TypeScript وبناء الواجهة وتشغيل pytest |
| إعدادات الصفحة | Issues مفعلة، وWiki وProjects معطلتان للحفاظ على تركيز المستودع |
| الموضوعات | `cybersecurity` و`encryption` و`fastapi` و`react` و`python` و`typescript` و`information-security` و`web-security` |

راجعت صفحة المستودع بصريًا بعد النشر. ظهرت الشارات وصورتا الواجهة والعناوين العربية ومجلدات الطبقات والإصدارات كما هو مقصود، ولا تحتوي الصور على رسالة حقيقية أو بيانات اعتماد.

## الحقوق والعلنية

المستودع **عام للعرض والمحفظة المهنية**، لكنه لا يرفق رخصة مفتوحة. ووفق توثيق GitHub، غياب الرخصة المفتوحة يبقي الحقوق الافتراضية لصاحب الشيفرة، لكنه لا يوقف عرض المستودع العام أو fork أو clone له [1]. لذلك لا يُنشر في المستودع أي مفتاح أو Secret Code أو رسالة حقيقية أو رابط صالح.

> العلنية تقوي قابلية تقييم المشروع، لكنها ليست وسيلة لحجب الشيفرة. حماية الأسرار تأتي من عدم رفعها أصلًا ومن إدارة المفاتيح خارج Git.
